# D3 — 因果风险属性的增量用途评价（结果前冻结）

日期：2026-09-12。来源 main：2c45288df40f8f4447021453aa34277b79817c44。

## 1. 问题与边界

在固定 E-15 时点，冻结 V19 交付状态/转移及原有恢复属性，是否帮助区分下游关心的后续风险，并超越上一确认状态与简单历史波动？这不是 V20、不是策略/方向/PnL研究，不修改 V9/V16/V17/V18/V19/D1/D2。
三层结论必须分开：工程一致性、未来风险信息价值、策略经济价值。D3只检验第二层；causal表示单边可得，不是干预因果或最优性证明。

## 3. 时钟、cohort和未来结果

主决策t=当前bar结束e减15秒，只消费D2在t已发布且尚未过期的E15事件。上一确认状态来自同日先前CLOSE；不得把当前CLOSE字段用于E15特征。D2原始网格与缺失记录保留，所有排除逐项计数。

固定H=15/30/60墙钟分钟，n=H/5。标签只使用从e到e+H的n段完整5m close-to-close收益r，全部区间起点严格晚于决策t。当前bar的收益完全不进入未来标签。要求所有未来节点同一交易日且在同一上午/下午连续交易段，时间差均为5分钟；不跨午休/隔夜、不把缺窗口补0。不同H有各自边界cohort，所有基准/增强模型在同一H严格使用相同记录。

两个共同主endpoint（共6个endpoint×horizon）：
1. log_future_sigma = log(max(sqrt(mean(r_future^2)),1e-12))，平方预测误差评价；不是累计方向收益。
2. future_tail = 1{max(abs(r_future)) >= 3*bg48_at_t}，Brier误差评价。bg48_at_t只取t之前48个有效已确认5m收益的总体标准差；未来不能改动这个归一化阈值。

辅助描述：未来CLOSE风险比例、未来是否出现NORMAL（仅当前风险状态）；这些依赖已有状态定义，不能单独触发效用晋升。冻结恢复概率是原目标的属性，不将其重命名为新的墙钟概率，不以本次辅助描述冒称重新校准。

主分析不加新鲜度阈值、不删除D2原有可用E15行；按<=15秒、>15秒固定描述层报告，另列15:00端点。没有完整未来窗口的端点仅保留适用性记录。观察年龄不是实测feed延迟。

## 4. 固定比较器（只作信息探针，不部署为新模型）

对每个主endpoint/H使用同一种固定线性ridge探针，目标是受控比较信息集；不搜超参数，不选赢家后修改特征。所有时间标准化/拟合仅用Development。

共同编码：symbol one-hot、48个固定bar_end slot one-hot（09:35–11:30、13:05–15:00）、上一确认三状态one-hot、因果最近确认冲击年龄桶[无、<=2、3–5、6–8、>=9 bars]。连续历史特征：过去3/6/12/48个有效已确认收益RMS的log、log(bg48)、上一个已确认绝对收益/bg48的log1p。收益日内diff，不造跨夜收益；滚动有效收益历史可跨日，沿用现有参考口径。午后既有历史口径保留且明确午休标志，不在D3修复V19。

- B0：共同分类编码（上一确认状态/年龄/日内时点/指数）。
- B1：B0 + 上述简单历史波动连续特征；这是主基准。
- B2：B1 + D2交付当前三状态、上一确认状态×当前状态9格、exit_pending、recovery_available及三条原冻结恢复概率（不可用时填0同时有mask，不伪装为0概率输出）。这是主增强。
- B3：B1 + log1p(E15 shock_intensity)、log(max(E15 vol_ratio,1e-12))、二者平方与乘积；这些5项再与上一确认状态相互作用。这是已有实时数值信息的较强基准。
- B4：B3 + B2的交付增量字段。B4对B3只检验状态表达的额外预测便利；状态本是价格历史的确定函数，不宣称创造了信息。

每个训练列按Development均值/总体标准差标准化；零方差列缩放置1。截距不惩罚；最小化mean squared error + 0.01*sum(beta^2)。二元endpoint用同样ridge线性概率探针并截到[0,1]后算Brier；这不是重新拟合冻结恢复表。无阈值选取、窗口选取、特征选取或Validation校准。模型字节在Validation评分前落盘并绑定SHA256。

## 5. 不确定性与结果前实际门槛

主比较B2-B1与强基准比较B4-B3，2 endpoints×3 horizons×2 comparisons=12项固定族。不挑单个最漂亮结果。

按交易日同时汇集两个指数，按每个年份顺序每5个交易日形成非重叠依赖块（尾块保留）。5000次按年份分层的配对块bootstrap，seed=20260912；两指数/同日/重叠窗口在同一块中，重采样保留每行权重。对12项用Bonferroni双侧区间分位0.05/(2*12)与1-0.05/(2*12)。另报告固定20日块敏感性，不凭其结果改主判定。区间为有限样本bootstrap近似，不是独立事件证明。

单项增量支持须同时满足：
- 对应Validation样本>=10000；Development>=20000；每个Validation年度/指数切片>=1000；future_tail项还要求Validation>=100正例；
- B2相对B1（或B4相对B3）的log-vol MSE相对减少>=1%；tail的Brier绝对减少>=0.0005且相对减少>=1%；
- 配对5日块、12项调整区间的误差减少下界>0；
- 2024、2025及两个指数分别误差减少>=0；
- 时间可行完整网格中状态+历史输入可用率>=95%，未改cohort/门槛/参数。

至少一个主比较通过，才可称具体endpoint/H下历史基准之外的风险信息效用得到支持；必须明确哪些没通过。仅B2通过而B4不通过，只能称相对旧信息有用途，不称状态压缩优于已有实时数值。两者全不通过则D3_NOT_SUPPORTED，不改冻结V19也不宣告它无工程或描述用途。B0等其余比较只描述，不增设晋升路径。统计显著但未达实际门槛亦不晋升。
