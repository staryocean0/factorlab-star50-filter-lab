# RMR signal-source discovery authority — 2026-09-09

## Repository mission

This repository is the **broad trend-reversal / mean-reversion signal-source discovery program**.

Its job is not to optimize one strategy indefinitely. It should discover structurally distinct sources of reversal / mean-reversion behavior, give each a bounded shallow mechanism budget, and hand promising sources to specialist research identities.

A strategy/source may be studied in detail for a while if it is producing coherent evidence. Once a source is clearly promising, the broad repository should report it as handoff-ready rather than continue unlimited optimization.
