## 三项关键陷阱

1. **时区**：旧源时间字符串带Z，但其数字部分是上海墙上时钟。按前19字符localize Asia/Shanghai；不要先当UTC再转上海。`trading_day`需与转换后日期一致。历史`available_at`为获取可用语义，不是源头逐笔实时接收证据。
2. **采样密度**：中证1000在2015的观测573,918行、2021为692,923行、2023为1,148,977行；科创50有类似变化。中位步长仍为3秒，但大量>3秒间隔随年份变化。不能拿每年行数增长当成交易事件强度增长。源快照既不是逐笔成交事件流，也不提供真实OFI、撤单、订单簿深度或买卖方向。
3. **同秒与修复**：3秒数据存在346条同秒额外源顺序行，按(symbol,observation_datetime,row_index)主键没有重复；全部保留，不静默取最后一条。分钟保留`causal_flat_fill/source_minute_count/high_frequency_analysis_eligible`等标记。对高频分析须明确eligibility和缺失规则，不能将修复平价分钟当真实平稳行情。

原始3秒价格为指数点，amount为区间成交额CNY，volume为null；不把amount当成交股数。日内、午休、隔夜和集合竞价要分开；不得跨源缺口插值。新15s/30s价格观察网格如要测试，应明确为单边观测测量，不冒称新DataHub OHLC产品。
