# 三种处理方案：逐项与组合验证

2026-09-06，本地完成。原策略不变、同一满单位账户，比较A近期位移集中度否决、B决策K线显著反向否决、C原L3通道优先，以及全部冻结的叠加组合。

## 结论先行

**A有成本敏感型的研究价值，但没有验证出用户设想的持续聚集机制；B改善较小、证据弱；C当前版本不适合无条件前置。三个直接叠加更差。** 没有一条可以宣布为已完成真实ETF/期权经济验收、稳定解决最大回撤的新策略。

尤其需要区分两件事：A在原零费口径仅将MDD从14.32%降到13.97%，却把年化从86.76%降到73.18%，这一交换本身不强；加上事先固定的每边万2费用代理后，少做低质量交易才体现出净价值。它不是“原算法风险已经大幅解决”。

本轮按项目Skill执行先冻结、基线先行、逐年人工图审、保留失败、完整账户重放。没有按年度改公式，没有调仓位或扫描阈值，也没有使用2026。2020只做暖机与无收益的价格分布标定；2021—2025均为已消费研究材料，不是新样本外。

## 1. 到底测试了什么

- **F**：原5m+0、一阶LP12、sigma48/ddof0、k1滞回、原下一开盘多空满仓signed-log指数账户。原入场不只是斜率转向，还要求越过反手门槛。
- **A**：在真正的原反手决策时，检查过去12根log收益的位移集中度`12×sum(r²)/sum(|r|)²`。超过2020分布75分位1.7603048576时拒绝新方向；旧仓正常退出，空仓到下一次原反手。不需要事后波峰。
- **B**：新信号看多，但决策K线`log(close/open)`跌幅超过此前48根收益的1σ；或看空却同等幅度上涨，则拒绝该次新方向。小幅反向允许。只使用买入前已收盘的决策K线，不看进场之后的走势。
- **C**：复用L3注册身份中的P48→P96通道子策略，保留原生15m+5、原参数与反向轨退出。用已完成15分钟决策向后as-of接到共同5分钟执行网格，不使用更晚报价，不双重延迟，也不引入暴跌反弹或后来三秒/一分钟的其他策略。
- **AB**是“A或B任一否决就不入场”；AC、BC、ABC均为C先认领，A/B过滤余下滤波入场。C的原生命周期不变；责任切换但方向相同不伪造新交易。`channel_only`只是组件对照。

共9个身份，参数与组合在结果前固定。入场后绝对仓位始终为1；空仓来自条件否决，不是把10万元只投入1万元。完整方法见[冻结合同](method.md)。

## 4. 第一条：有没有类似波动率的聚集？本轮没有支持

为了避免滚动12根窗口共享11根K线造成伪聚集，改用每日四个不重叠12根收益块。阈值不变，观察下一块是否仍高集中。

|比较|过去高Q后，下块高Q|过去低Q后，下块高Q|两种修正后参照比例|
|---|---:|---:|---|
|日内相邻块，3636对|18.08%|17.42%|0.9260 / 0.9285|
|相邻交易日末块→首块，1207对|36.28%|33.27%|0.4485 / 0.4285|

均未通过。**不能据此建立“观察到陡峭，就推断后面持续陡峭”的状态机。** 这是否定本轮Q12定义、时间尺度和参照下的证据，不证明其他尺度、方向性或状态定义都不存在聚集。

为什么A却有一点收益价值？事实只是：入场时已知的近期集中度，选出的交易在成本后较弱。其效果可能涉及冲击后滤波状态/波动门槛尚未恢复，而不必依赖下一段价格仍集中；后者只是待验证解释，不能把A的净收益改善倒推成聚集机制已经成立。

## 6. 为什么A+B并不比A更好？两条条件的重叠很重要

|原交易所属桶|交易数|平均净log收益bp|
|---|---:|---:|

**交集82笔是值得保留的后验弱桶线索，但本轮没有把“仅同时命中才否决”追加成第10个策略。** 没有计算它的完整账户MDD，不能称交集策略已经通过。若继续，应另冻结该交互条件；不得把事后选出的子桶当独立验证。[重叠分解](../../../artifacts/three_proposals_v1/veto_overlap_attribution.csv)

## 7. 第三条：为什么现有通道前置不合适？

身份已从L3研究注册表核对到P48→P96通道子策略，原生15分钟与参数保留。它仍是待重新资格审查的研究策略，不具有交易/生产权限。本轮没有把“高斜率通道”这个名字换成另造的快线。

实际它认领了约**85.2%的记账区间**，只给滤波留下14.8%。这不是只接走少量尖峰，而是大面积替代原滤波。方向替换损失的毛log价值约1.15161，节省费用约1.05131，费用后仍落后；2022年6月14日至8月4日形成23.67%的零费回撤。

它不是完全没有互补价值：在原2022年10月24日至11月11日最大回撤固定窗口，F为-14.32%，C反而+4.51%。**但它在别处制造了更大的回撤。** 因此不能只因为修复了已知最坏事件，就将它全局前置。

结论仅针对本次原生15m+5、P48→P96及无条件优先架构；不否定其他已有更快尺度或另行冻结的条件性交接。该15m+5视图每天14根的稀疏性也保留，没有擅自补bar或改周期。

## 8. 原来的回撤改善了，新的最坏回撤在哪里？

固定原峰谷窗口，A/AB把-14.32%缩至-10.94%；但A自身最坏回撤转移到**2025年9月8日至26日**，仍达13.97%，AB为13.65%。B在原2022窗口反而恶化到-15.25%。这些固定窗口收益不是各策略自己的MDD，两种表分别保留。[固定原回撤窗口](../../../artifacts/three_proposals_v1/original_mdd_window.csv)

这说明当前过滤没有统一解决所有回撤类型，不能只盯着最初那一段宣布成功。

## 9. 稳定性与最终取舍

A费用后年收益在2021—2023优于基线，2024—2025落后。2025尤其重要：A收益15.60%对基线25.12%，MDD15.18%对11.57%，单笔均值也略低。A在20季度中12个正增量、8个负增量；按0.00025收益变化门槛有19个受影响季度，其中12个为正。AB仅11/20季度正增量。不能把全期小幅优势说成近期稳定有效。

建议保留顺序：

1. **A作为成本敏感型研究材料优先保留**，不是已完成的降回撤策略；其收益交换依赖费用且近期失败。
2. **B保留为小幅、弱证据的备选**，不立即独立推广或调阈值。
3. **不采用当前C全局前置，也不采用ABC直接叠加**。它们的回撤明显更大。
4. A/B重叠桶作为下一轮可冻结的交互线索，不能未经完整账户检验直接上线。
