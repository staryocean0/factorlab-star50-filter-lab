# 首冲击秒级路径与增量信息 V2

本版本保留V1全部历史。结果前协议见`protocol.json`；代码级数值由该协议记录，不是可自由调参的配置。

主实验使用15秒端点测量、分钟决定时钟与未来2—15分钟首事件标签。30/60秒仅作测量审计，不宣称选择了最优频率。

**质量口径：** 主测量端点年龄不超过3秒，跨越大于15秒源缺口的收益为未知；它不是完整3秒事件路径。严格3秒连续支持另作敏感性。没有插值、改价、订单簿或交易事件强度推断。

B0、B1、B2在同一组时点和相同目标上重新拟合；B0不是沿用V1拟合权重。B2相对B1才是跨尺度信息的主增量比较。

告警模板随机参照通过带约束指派保持总告警时间、持续长度、时钟位置和粗波动组，可能包含自匹配，不是均匀精确置换检验。

事件与近邻控制账本为事后诊断，不能把其case-control比例当总体风险。缺口和同秒多记录时不声称识别了真实冲击起点。

运行（本会话本地只运行工程测试；市场计算交给已授权Actions）：
```bash
D=docs/research/first_shock_seconds_v2
python -m pytest -q "$D/tests"
python "$D/code/seconds_v2.py" --root . --out evidence/v2
```

原始路径、预测和估计器留重放artifact；小型账本／年度汇总／测试日志留审阅artifact。空输出、支持不足与未执行事项均不写为科学通过。

实现参考：scikit-learn官方Common pitfalls / Pipelines文档，仅训练期拟合预处理；所有市场发现须以实际运行证据为准。
