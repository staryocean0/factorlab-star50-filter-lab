# 因果未来波动三桶工具 V1：结果前合同

用户授权试做因果分桶工具，检验能提前发现多大的未来波动变化。此前93%/59%为事件在事前高σ状态内的覆盖率，不是聚集率或预测精度；标准化事件也不会自动达到90%。本轮工具输出未来波动预测/风险状态，不输出交易方向，不改V2或通道。

## 数据和时间

使用已验收 `tail_distribution_v1/panel_1m.parquet` 的两指数共同1m面，绑定来源SHA和prepared回执；2021—2022拟合，2023校准，2024—2025固定重复历史检验。两指数分开拟合但模型结构和参数完全相同；2026不读取。1m为本轮决策频率，预测未来5/15/30个交易分钟，15分钟为主、5/30分钟为尺度诊断。不搜索模型、窗口或正则参数。

## 真正前向的标签

时点t只用已经闭合的bar。标签 `v_future(t,h)=mean(r_(t+1)^2,...,r_(t+h)^2)`，波动水平 `sigma_future=sqrt(v_future)`，单位为1分钟log收益的RMS；也可乘sqrt(h)得到窗口平方收益尺度，但不是有符号涨跌幅或价格区间保证。过去比较窗 `v_past_h=mean(最近h槽位的有效r²)`。当前r_t不进入future，两个窗口不重叠。

未来窗口必须完整落在同一上午/下午连续会话，跨午休、隔夜和数据末尾都不给预测/评价。开盘首棒不作为普通r；其已知body和gap可作条件，但不能声称预测到了已经发生的开盘跳变。过去特征可沿交易时钟跨会话读取历史普通r，至少80%有效；前480槽位预热不足时不输出。

## 固定模型与基线

主模型是HAR思想的日内多尺度log方差ridge原型，不冒称原论文原样实现。特征：过去5/30/480交易分钟的log均方收益、当前已知body与开盘/午休gap相对慢波动的幅度，以及8个固定半小时交易时段哑变量（一个作基准）。ridge λ=1，特征均值/标准差仅拟合期估计，截距不惩罚。数值方差地板1e−12，非经济筛选门。模型一次拟合，2024/2025不重训。

基线：同长度过去波动的persistence；以及拟合期按收线时刻的平均未来方差clock-only。两个基线不作为待择优策略，与主模型同一支持集报告。

2023校准主模型的log方差残差分布。点预测使用校准残差的smearing均值修正；10/90分位给名义80%的未来波动预测区间。高波动/2倍/3倍/4倍放大的概率来自该经验残差CDF。该区间和概率不是有保证的conformal覆盖，时变分布和残差异方差可能使覆盖失效，必须报告实际检验覆盖。

方法背景：Corsi (2009) HAR-RV利用多个历史尺度的波动解释未来波动。本原型尺度和附加条件为本任务设计，不沿用原论文日/周/月数值。[原论文](https://doi.org/10.1093/jjfinec/nbp001)。

## 三桶和变化定义

各指数/预测长度用2023真实未来sigma的33.3%、66.7%分位冻结低/中/高桶。预测桶由点预测落在哪个区间决定；另报告 `P(future_high)`。定义实际放大事件：future_sigma≥k*past_sigma_h 且future_sigma≥高桶门界，k=2/3/4。这排除安静状态下两个很小数相除产生的虚假巨大倍率。

固定告警：预测相应事件概率≥0.5。报告精确率、召回率、时间覆盖率、误警率及样本数；即使零告警也如实报告。为直接观察倍率估计，还报告点预测比率≥2/3/4的相同指标，不能据结果切换哪个告警规则。

点预测倍率告警也必须满足预测波动进入高桶；不能因两个小数的比值较大就发经济风险告警。

“从平静到突然放大”单列：上述放大事件，且past_sigma_h低于高桶门界、过去5分钟没有绝对收益/body/边界gap超过已冻结29.036bp的明显冲击。该定义只表示已声明条件下的未见前兆放大，不能证明世上没有其他先兆。即使预测命中也不代表能避开源窗口第一下损失。

## 评价与统计单位

主要指标：波动log RMSE/倍数误差、Spearman、三桶混淆矩阵、高桶precision/recall、80%区间覆盖率。变化倍率单独评分，不能拿水平预测代替变化预测。

密集逐分钟输出可用于工具，但重叠标签不是独立事件。每会话另取相隔h分钟的决定点作非重叠评价；共同日/时点与年级分解全部保留。核心15min两指数的主模型对persistence平方log误差差值，以5交易日移动区块bootstrap 999次给97.5%区间（两指数Bonferroni参考）；其他指标描述，不追加多轮显著性选择。

“高准确”不预设百分比门，也不拿高桶时间覆盖扩张冒充成功。2023分位冻结后，2024/2025桶占比可以变化，必须列出。整体未来高波动与真正首次放大的表现分开判定。只授研究工具身份，交易路由要另测策略净效果。

## 可复现与接口

模型、校准残差、阈值和来源一并冻结。预测接口只接收当前及过去的r/body/gap/时钟，不接收future标签；缺历史或窗口跨会话时返回不可用。测试前缀不变、未来突变不改变此前特征/预测、目标时间不重叠、模型训练期、区间概率单调、分桶分母和零事件场景。保存逐点输出、非重叠账本、混淆矩阵、年度/倍率报告、图形和源哈希。
