# 因果未来波动三桶工具 V1：结果

研究原型已完成。未来波动水平预测优于“沿用过去波动”，但普通交易时段的突变预警尚未通过，不能据此接管交易路由或宣称减少最大回撤。V2策略不变。

## 先纠正旧指标的含义

旧研究中约93%/59%是“大且超背景异常”的分钟落入事前高波动桶的比例，不是时间聚集率，也不是预测精确率。两个指数高波动桶分别占约65%/45%的时间，覆盖面不同。只看标准化异常，事前高桶捕获率约61.53%/40.72%，并没有都升到90%。两者一分钟标准化事件均有时间聚集证据，但聚集不意味着第一下冲击可以预知。详见[原研究](../tail_distribution_v1/result.md)。

## 实际预测了什么

2021—2022拟合、2023校准，模型冻结后依次检验2024和2025；均为已消费历史，`fresh_oos=false`，没有读取2026。两指数相同一分钟网格，分别拟合相同结构，预测未来5/15/30分钟，15分钟为主。

在第t根K线闭合后，用过去5/30/480分钟波动、已知当前振幅与边界跳变、固定交易时钟，预测后续t+1至t+h的均方收益。未来波动为其平方根，单位是每分钟log收益RMS，不是方向预测、累计涨跌幅或价格区间保证。未来窗口不跨午休或隔夜。方法受多尺度波动模型启发，并非原样复现[HAR-RV论文](https://doi.org/10.1093/jjfinec/nbp001)。

三桶界限是各指数2023年真实未来波动的三分位点，随后固定。15分钟低/中、高桶界分别是：中证1000每分钟2.839/4.150bp，科创50每分钟4.396/6.733bp。它们不同于旧研究的过去480分钟标准差桶，不能直接混用捕获率。

## 未来15分钟波动水平

以下为2024—2025逐分钟评价，每指数101,850个可用决定点。

| 指标 | 中证1000 | 科创50 |
|---|---:|---:|
| 多尺度模型log波动RMSE | 0.3265 | 0.3229 |
| 沿用过去波动RMSE | 0.4073 | 0.3833 |
| 仅交易时钟RMSE | 0.4862 | 0.5157 |
| 预测误差中位倍数 | 1.239 | 1.228 |
| 三桶总体准确率 | 74.83% | 71.01% |
| 三桶均衡准确率 | 55.77% | 63.57% |
| 高桶精确率 | 83.29% | 82.35% |
| 高桶召回率 | 91.87% | 86.59% |
| 标记为高桶的时间比例 | 75.08% | 56.88% |
| 真实高桶时间比例 | 68.07% | 54.10% |

中证1000超过90%的高桶召回，是在约75%的时间都标为高桶的条件下得到的，不能解读成90%精准预警。误差中位倍数衡量sigma相差多少倍，也不能称为涨跌预测准确率。

名义80%预测区间实际覆盖率为79.45%/77.86%，上下界中位比值约2.17/2.06。区间来自2023全局经验残差，非保证覆盖的conformal区间。相对沿用过去波动，平方log误差差为−0.05929/−0.04267；五交易日移动区块bootstrap的97.5%区间分别为[−0.06419,−0.05482]/[−0.04702,−0.03807]。这是重复历史中的水平预测改善，不是新样本盈利证据。

## 真正关心的突然放大

“翻倍”定义为：未来15分钟sigma至少是过去15分钟的2倍，而且进入真实高桶。固定预测概率≥0.5才告警。精确率=命中/告警，召回率=命中/真实事件。

| 逐分钟评价 | 中证1000 | 科创50 |
|---|---:|---:|
| 全时段真实翻倍窗口 | 3,394 | 2,673 |
| 全时段告警/命中 | 772/731 | 832/760 |
| 全时段告警精确率 | 94.69% | 91.35% |
| 全时段翻倍召回率 | 21.54% | 28.43% |
| 每半日开市30分钟后真实窗口 | 1,501 | 1,081 |
| 开市30分钟后告警/命中 | 31/22 | 13/5 |
| 开市30分钟后精确率 | 70.97% | 38.46% |
| 开市30分钟后召回率 | 1.47% | 0.46% |

**90%以上精确率主要来自每半日开市附近的可预期波动抬升，并没有解决普通时段突变。** 第一决定点9:31/13:01的翻倍召回约91.5%/91.7%；这利用已闭合首棒与交易时钟，不能声称预测到了首棒之前的跳空。进一步限定过去平静且最近5分钟没有明显冲击，开市30分钟后仅命中21/1,107和3/814个翻倍窗口。

5分钟尺度的普通时段翻倍召回也只有8.06%/5.99%；15和30分钟尺度的3倍、4倍事件在固定概率门下没有告警。零告警不表示事件不存在；也不能证明其他模型、特征或阈值永远无效。本轮不按结果重调阈值。

这些“事件”是相互重叠的预测窗口，不是去重后的独立冲击次数。首相位非重叠取样会放大开市效应，因此保留全部相位敏感性，不挑表现最好的相位；各相位计数相加与逐分钟计数一致。时段分解为结果后的机制诊断，不是新交易规则或独立确认集。

## 接受边界与验证

- 接受：过去信息到未来波动的因果研究接口；相对持续性基线的波动环境预测进展。
- 未通过：普通时段突然放大的有效覆盖；滤波器/通道交易路由；最大回撤或杠杆改善。
- 没有将指数研究转成实盘工具，也没有修改V2、优化交易参数或打开2026。
