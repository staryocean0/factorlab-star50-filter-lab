## 4. D3实际回答了什么

协议在43d46e211656e086a40c7a61c622674baa7b6011提交；仅Development2021–2023拟合30个固定ridge信息探针，Validation前提交模型hash回执78c12f27f43107b0b1f08902b75be4af09e9c638，之后评分2024–2025。不重拟合V19/恢复表。

相对上一确认状态/冲击年龄/时点/指数+简单历史波动，当前状态/转移/恢复属性使MSE相对减少0.46336%/0.74191%/0.91026%，Brier减少0.81010%/0.79116%/0.65491%。6项调整后的5日块区间为正、年度/指数方向一致，但均低于1%实际门槛；15/30m尾部也未达绝对0.0005门槛。不降低门槛、不选窗口改判。

基准已经使用同一时点连续冲击强度与波动比率时，状态额外改善约0.003%–0.058%，6项区间跨0。这说明固定探针下标签表达不是已证实的额外强预测优势，不是所有消费者均不可能受益。

NORMAL/RECOVERING/UNSAFE的15m尾部窗口比例2.8136%/3.9807%/10.0386%说明环境区分存在，但增量幅度另当别论。前置窗口的唯一未来冲击捕获134/527亦不能和V19现有episode捕获率互换。不能用自身定义一致性、风险桶基准率差异或工程零漂移代替增量验收。

## 5. 现在交付的用途定位

V19/D2保留为**因果状态注释、风险环境描述与消费者组织基线**；暂不晋升为“已证实有足够增量的未来风险预测门控”。这一限定位不是停止所有研究，也不是策略层获得交易许可。

NORMAL非安全保证，UNSAFE非看空/禁止一切交易，RECOVERING非开仓许可，UNAVAILABLE非NORMAL。HighVol或连续属性不能偷偷作为V19第四状态；另列定义、来源、当时可得性和验证身份。

实用评价要真正约束晋升，也允许得出未支持结果。1%是D3事前效应要求，不是所有经济应用通用定律；不能为本次结果降低它。
