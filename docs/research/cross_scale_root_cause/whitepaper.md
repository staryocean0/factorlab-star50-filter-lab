# 数学定义、数据对齐与证据边界

## 原始账户

令x_i=log(close_i)，O_i=log(open_i)。以首个2020可用x_0为原点，一阶因果低通W由`butter(1,1/12,fs=1)`和`sosfilt`产生。等价递推为

W_i=0.5773502692 W_(i-1)+0.2113248654 [(x_i-x_0)+(x_(i-1)-x_0)]。

前12根为预热NaN。sigma_i是最近48个Δx的总体标准差（ddof=0），包含当前收盘。多仓追踪W运行最大值，空仓追踪最小值；斜率反向且离极值超过sigma时反手。无年度重置。

信号s_i在close_i后形成，原实现p_i=s_(i-2)，r_i=p_i log(open_i/open_(i-1))。p_i归属于已完成的开盘区间，不是时刻i之后的仓位。2021净值以1为原点，指标、持仓及跨边界区间继续；signed-log空头账户不是现金ETF收益。

本轮调用原模块，未重写或覆盖旧公式。双向解释分量从不输入原始s_i。图上源timestamp是上海交易墙钟的结束标签，剥离源Z包裹而不转时区。历史字段available_at与盘中接收时钟分开；接受用户实时语义。

## 分量、回看期与20项属性

解释用L_P(x)=`sosfiltfilt(butter(1,1/P,fs=1),x-x_0)+x_0`，P=12/48/240/960。五个分量b依次为x-L12、L12-L48、L48-L240、L240-L960、L960，逐点相加等于x。前后向滤波使用未来，幅度响应为单向响应的平方；它不是原策略的因果低通，也不是硬边界频带。[SciPy原始文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html)

N为该原生视图每日观测数，主图48，5m其他偏移46。R_H=sum_{HN}Δx，A_H=sum_{HN}|Δx|。所有属性取日末快照；尾随窗口并不能使双向分量因果化。

| 属性ID | 定义 | 回看/未来 |
|---|---|---|
| eff_1d/5d/20d | abs(R_H)/A_H | H日；完整当日未来对盘中不可得 |
| rv_1d/5d/20d | sqrt(mean_(HN)(Δx²))×10000 | 每原生根bp，含漂移的二阶矩，非去均值std |
| rv_ratio_1_20 | rv_1d/rv_20d | 1与20日关系 |
| drift_disagree_1_20 | sign(R_1)≠sign(R_20) | 无方向大小估计 |
| acf1/3/12_5d | corr_(5N)(Δx_i,Δx_(i-lag)) | 固定lag；窗口与滞后不同 |
| fast_share_1d/5d/20d | sum(Δb_fast²)/sum_j sum(Δb_j²) | 使用未来；非正交相对变化，不是解释原收益的方差占比 |
| work_turns_5d | 工作分量Δb符号变更次数/5 | 次/交易日；使用未来 |
| slow_work_velocity_5d | RMS_(5N)(ΔL240)/RMS_(5N)(Δ(L12-L48)) | 慢>5日相对1小时—1日；使用未来 |

除零保护1e-15。两个分量平方项一般有协方差，因此fast_share不能称“价格噪声百分比”。常数趋势水平对差分无影响。sigma为48根std，与rv属性的RMS及原生视图N不是同一个量。

原生14视图仅比较效率和影线，不在稀疏60m视图上伪造连续均匀傅里叶频谱。5m偏移cutoff仍固定12根；46根/日会使标称交易日尺度略偏，不调参弥补。

## 后验联合格与推断

两张2×2表：fast_share_5d×slow_work_velocity_5d，eff_1d×eff_20d。两位编码第一位对应第一个属性，大于面板中位数为1，否则0。全开发面板中位数只用于描述，未按收益优化；不得用于实时策略。CSV读cell应保留字符串，00与01不是数值0、1。

20属性、log损益与捕获率两个结果，共40关联。每年分别求列秩、去掉该年的秩均值，再按全期平方和归一化；相关为标准化秩列内积，故不是简单逐年rho平均。辅助年度/偏移表使用普通Spearman，与主表数字略不同。

循环参照在每年把整个20维属性面板共同平移20至n-20日，结果序列固定；分块参照在每年置换连续20日属性块，末块允许较短。两者保留属性间关系和一定序列结构，破坏同步关系；循环接缝及分块接缝仍存在，年内状态非平稳可能影响校准。每次max(abs(rho))跨全部40项，p=(1+超过次数)/2000。两种参照分别报告，不挑较小者。

置信区间为1000次按年配对循环移动20日块bootstrap，抽取同一组属性与结果、重新求秩，用2.5/97.5百分位。不是40项同时置信区间。非重叠5日块把原始日属性取均值、损益及绝对路径求和后重算捕获率；属性本身仍有20日重叠记忆。

固定格按同年×当日rv三分位与其余格比较；报告每层与按目标格样本数加权的差异。不是随机化因果处理。日末标签匹配完整日损益，属于后验关系。由已知回撤选出的峰谷条件贡献更不是独立验证。

不能用“未拒绝”宣布已经证明随机，也不能用“拒绝同步错位”宣称宏观低频经济因果。替代序列检验的结论取决于所保留的约束与原假设。[Schreiber与Schmitz的原始方法综述](https://arxiv.org/abs/chao-dyn/9909037)

## 交易形态与结构扰动

原账户连续相同p的区间划成持仓片段；其中累计log损益最大值与0取大为MFE、最小值为MAE，giveback=MFE-net。只在原有开盘记账节点测量，不利用盘中高低点假设可成交。全样本第一和末片段截断标记；事件首末片段另行裁切，不能将这些片段叫独立完整交易。MFE属于事后持有期间的有利位移，不是策略可获得的额外利润。

原价格logopen/logclose分别做同一双向分解，合并成fast=x-L12、medium=L12-L240、slow=L240。七个非空组合逐一重建正的O/C价格、共同常数平移保持数值尺度、重新计算同一个sigma/信号/满仓算法；all三者重建的持仓必须逐点相同、损益容差2e-14。其他组合可以改变信号，但属于数学输入扰动，不是仓位风险政策。H/L不参与这些合成账户，也不宣称其具有原市场的完整OHLC一致性。

这类扰动会改变可预测性、波动结构、峰谷和门槛，不能当成现实无某频段时会怎样。其夸张年化数据完整留档作诊断，正文不据此宣传可实现收益。另以原固定持仓乘各open分量差分，验证损益重建；非正交分量不产生独立经济责任。

受控波形x_t=.002 sin(2πt/P)+q·.002·960/P·sin(2πt/960+phase)。P固定6/8/12/24/48/96/240，q=0/.5/2，phase=0/π/2/π，共63例（q=0的相位重复仍计预算）；另21例用恒定漂移v=.002·2π/P·{-0.5,0,0.5}替代慢波。9600根，前1920丢弃；open为前close，无跳空、噪声与费用。原策略原门槛原时序重跑，只报捕获率与信号行为，不校准市场参数。
