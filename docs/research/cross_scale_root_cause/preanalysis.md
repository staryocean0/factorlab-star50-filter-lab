# 固定策略的跨尺度根因：预分析

用户假说是高频交易可能被低频状态持续牵制。本轮不增设交易规则，也不把回撤深度必然解释为非随机。先冻结有限菜单，然后让盈利反例、跨年/偏移与保留依赖的错位参照反驳假说。此前已见基线和前十大事件；预注册只能限制新增尝试，不能恢复盲态。

金融链条：短周期往返幅度或速度若不能覆盖低通相位滞后、滞回与下一开盘执行，固定信号会在波段后段接手并返还利润；慢漂移可能偏置某一方向，也可能提供稳定收益。分别观察路径效率、回报自相关、各频段相对变化、慢/工作频段方向关系、门槛/波幅关系。高低频是候选原因，不是结论。

频段移除重跑回答“同一算法如何响应这种数学价格构造”，不是现实市场干预效应；固定仓位的分量损益只给记账恒等式，不能独立证明噪声有害。合成波形提供可控机制对照，不充当历史样本。

原账户完整保留，推断属性面板去掉全输入首尾20交易日；2020预热覆盖左端，2025末端不借2026补齐。频段的前后向滤波确实使用未来，绝不回填交易信号。SciPy方法定义见[官方sosfiltfilt文档](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html)。替代序列检验必须声明保留和破坏什么，参见[Schreiber与Schmitz的原始综述](https://arxiv.org/abs/chao-dyn/9909037)。

本轮是用户授权的后验固定策略归因。借用strategy-slice-rebuild的冻结、逐年人工审查、链式回执和不可变证据原则；不执行不适用的2009—2020十二年策略重建，不构造年度运行规则。全部结果属于已消费开发材料。
