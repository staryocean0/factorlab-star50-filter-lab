# 0.5交易日低通的采样比例小课题

目标固定为0.5交易日=120交易分钟，不是20交易日；承接用户刚确认的LP24一阶、斜率符号反手版本，不替换成LP12+σ滞回。只做理论与信号层诊断，不计算候选策略收益、MDD或选择交易参数。

2020—2024价格仅供已固定因果滤波预热/状态延续；2025为已消费的信号诊断材料，全年与已知4—9月分别报告；2026无行情或收益读取。输入只用已封DataHub原生1m_official与5m_offset_0，不本地制造新K线。秒级仅作频率响应数学计算，没有秒级真实行情或绩效证据。

## 固定对照

- M5：5分钟输入，P=24，比较相邻5分钟低通值，每5分钟更新方向。
- M1_D5：1分钟输入，P=120，只在原5分钟决策时点读取，比较相邻两个5分钟时点低通值。只改变采样输入，不改变5分钟斜率尺度/决策网格。
- M1_H5_D1：1分钟输入，P=120，用前5根1分钟低通之差，每1分钟更新方向。相对M1_D5只提高决策更新频率。
- M1_H1_D1：1分钟输入，P=120，看相邻1分钟低通之差，每1分钟更新。此例同时缩短斜率尺度，用来展示“直接把原代码放到细K线上”并非同一策略。

方向变化次数是信号变化，不是已成交交易或已证实假信号。短方向片段定义为两次变化间≤10个交易分钟；区间首尾片段不计此比例。零方向如存在单列，不自动改为保持旧仓。比较共同5分钟时点的输入close一致性、低通数值差异、方向一致性，以及各方案变化次数/短片段比例。

数学对照采样间隔30m、15m、5m、1m、15s、3s、1s，均使用相同一阶Butterworth物理截止120m。报告每周期样本数R、单次孤立坏报价的首系数、截止频率增益/相位延迟、相对于连续一阶低通的低频相位延迟偏差。这个偏差不是总体滤波误差，更不是最优收益比例。频率响应显示低通加相邻差分与固定5分钟差分的区别，频谱数学曲线不等于真实市场噪声估计。

另按原一阶系数直接验证代数恒等式：`y_t-y_(t-1)=b*(x_t+x_(t-1)-2*y_(t-1))`，其中x/y采用同一去初值log坐标，`b=tan(pi/R)/(1+tan(pi/R))>0`。因此相邻斜率符号等价于最近两点原log价格均值相对上一低通值的位置；b随细采样变小，不自动抑制符号翻转。所有方向计算保留原去初值坐标，避免绘图所加绝对价格常数造成近零浮点符号差异。

不将独立同幅报价误差缩小，与真实持续相同物理时间的冲击混为一谈；也不把真实跳空称为可被细采样消除的噪声。1分钟数据只是较细观察参照，不是不可见真实价格。对15m/30m的真实策略不作直接排名，因为已有稀疏偏移视图的缺口会混入时钟因素。

产物为响应表、共同网格信号比较、年度/月度诊断、输入与前缀一致性回执、技术报告。没有新策略晋级、生产或秒级最优宣称。
