# 固定信号的执行审计与反例归因

本轮是上一轮 `drawdown_conditions` 的后续测量审计。共同根、低通系数、波动率滞回以及慢冲突半仓公式均不变。没有新增策略候选或搜索最优延迟。研究范围仍为2020预热、2021—2025已消费开发材料；2026不读取、不排序、不验证。指数点多空账户不是可交易产品账户。

## 1. 三个时间必须分开

- `timestamp`：仓库明确说明其Z后缀包裹的是上海墙钟收盘标签；本轮沿用该解释。
- `available_at`：保留其显式时区，按真实带偏移时间转换为上海墙钟。五分钟源均标记当日15:30；不能直接覆盖成收盘标签。
- 开盘端点：原始一分钟收盘标签减一分钟是本轮约定的分钟开盘时刻。这个桶边界不等于真实第一笔报价的秒级时间。

普通五分钟bar的开盘是收盘标签减五分钟。偏移+1至+4每个上午/下午的第一根覆盖六个一分钟记录，必须减六分钟。如果首个一分钟记录被标记为缺失分钟前值填充，则按本轮事前补充规则查找该既有bar内首个未填充分钟，且其open必须精确等于既有五分钟open。这里只核对端点，不生成新的K线，不搜索对回测有利的价格。

上述两项边界是在2021输入端点校验失败后、首个年度结果封存前分别记录的基础设施修正。原预注册及补充协议全部保留。没有改原数据，也没有用收益挑选修正。价格恒等关系能闭合映射，但不能证明原始导出与缺失分钟修补的实际先后顺序；源版本谱系仍缺证。

## 2. 四种执行口径

1. `legacy_on_minute`：原先下一个同偏移五分钟bar的open成交，在一分钟open上逐分钟记账。每个原五分钟端点的累计净对数收益都必须与旧账户一致，容差1e-10。
2. `delay_1m`：同一冻结计划开盘时刻向后至少一分钟，采用首个满足时间条件的原始一分钟open。保留原五分钟计划对午休、隔夜的跨越，避免偷偷改变交易时钟。
3. `delay_1m_observed`：在2的基础上，成交不能使用标记为`causal_flat_missing_minute`的行。填充行仍保留为历史记账点，不能声称持仓分钟行情已独立证实。
4. `literal_publication`：严格等到`available_at`及所有递归依赖已发布，才在原计划开盘采用最新已完成信号。整批释放只取最新信号，不把过期盘中订单挨个补成交。本口径检查字段的字面含义，不证明真实数据服务有这么长延迟。

所有比较在每个偏移内共用一分钟价格端点、评分起点和2025最终平仓端点。2021首个评分开盘从空仓开始，指标可保留2020预热状态。跨2022—2025年度账户连续，不在年初重置持仓或重建策略。年度图的净值从1显示仅是展示尺度，年度首笔收益仍来自连续账户的真实仓位。

一分钟采样的MDD可能高于原五分钟采样，因此“新MDD−旧MDD”不能直接解释为延迟损失；应在相同一分钟记账粒度下比较1与2。

## 3. 完整账户及可加归因

在第j个分钟open，变仓前仓位为q_before，变仓后为q_after。收益与成本为：

`gross_j = q_before_j * log(P_j / P_(j-1))`

`turnover_j = abs(q_after_j - q_before_j)`

`cost_log_j = -log(1 - cost_bps * turnover_j / 10000)`

`net_j = gross_j - cost_log_j`

首笔、减仓、恢复、反手、最终平仓全部收费。+1到−1是两单位换手。原始载体是指数点，本轮使用与前轮一致的对数指数账户，未冒充ETF实际权益、融资、冲击、卖空或T+1路径。

慢冲突半仓与基线的毛收益差Δ逐分钟拆分：Δ>0为减少的亏损，Δ<0为放弃的盈利。两者均使用未来已经发生的区间收益，只能用于事后解释。

`净增量 = 避免亏损 - 放弃盈利 + 成本节省`

相同平均绝对仓位的常量对照进一步区分择时和单纯降低敞口。年度对照按该年的已实现平均仓位计算；五年对照按五年平均计算，两者不可混淆。常量系数使用了事后持仓分布，故是诊断基准，不能当可部署的动态规则。

延迟归因使用同一市场收益序列：`Σ(q_delayed-q_legacy)*market_log_return`，逐项等于两种执行口径的毛收益之差。MDD的峰谷会随政策改变，MDD差不是上述可加收益差，不能把回撤下降百分比拆成可加的“原因占比”。

旧慢冲突与锯齿状态沿各自实际执行信号来源映射到持仓区间，四格互斥：都无、仅锯齿、仅慢冲突、二者兼有。表中的成本是在变仓open发生，而毛损益对应变仓前持仓；因此条件格净收益不等于新订单的未来盈利预测。事件表另拆下降和恢复，保留无收益或缺机会的情形，不把它们升级成硬门槛。

## 4. 证据与科学边界

每年单独准备、主代理读图与事件、手写归因、摘要链封存，再打开下一年。所有策略都是前轮已冻结政策，本轮没有新模型、评分训练、TopN搜索、SSA准入或A0—A7新账户政策家族可供提升；所做的是既有指数诊断账户的执行一致性检查，不能宣称已通过可交易账户科学验收。

每年保存原始分钟记账点、稀疏变仓事件、期初期末仓位和数组摘要，合成完整的成本无关AccountSnapshot。最后报告只从封存快照推导，零原始数据读取、零信号计算、零订单调度重放；所有200个快照均需逐字节恢复原位置与损益数组。

一级意义是会计/测量机制，不是市场结构因果。低频状态不能仅因与某次亏损同时出现就被称为原因。也不能因为交易频率高就排除随机回撤；上一轮的排列参照保持不变，本轮没有为得到更强结论重复选择统计检验。

[上交所原始发布公告](https://www.sse.com.cn/market/sseindex/diclosure/c/c_20200619_5130634.shtml)确认科创50在2020年7月23日开始正式发布实时行情。这个事实支持“当时存在实时指数”这一点，但不能证明本仓库百度3秒衍生载体的15:30字段到底是首次可得、采集完成还是回填发布时间，更不能证明所用历史版本逐点盘中可得。
