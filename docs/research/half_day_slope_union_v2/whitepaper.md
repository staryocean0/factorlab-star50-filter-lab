# 科创50半日斜率并集 V2：以单笔质量优先的有界参数研究

本次用户明确授权：制作第二版，系统辨认未锁定参数及影响，优先平均每笔收益、减少抖动，同时追求高夏普，完成V1/V2回测及图形。V1原文件和封存收据保持不变。本合同在任何新历史价格/收益读取前写入。

## 目标与账户口径

本轮研究对象仍是000688.SH指数方向策略，1m、120交易分钟一阶低通、五斜率并集、多空镜像、满单位/空仓。指数本身不可买卖；报告明确标为“指数方向模拟”，零费用与每边2bp费用代理并列，4bp/7bp作固定成本压力。真实ETF/期权账户是另一评价层，不能把指数理论开盘价称为实盘成交。手续费预算不是查询到的当前报价。

主要目标是完整交易的平均净**简单收益**（bp），辅以中位数、胜率、盈亏比、利润因子、持有分钟、≤5分钟短持仓比例、交易数、日收益夏普、年化与最大回撤。短仓毛收益为 `−(exit/entry−1)`，多仓为 `exit/entry−1`；每笔本金按入场权益确定，单笔内份额固定，空仓收益0，无融资利息。为预留入场费用，份额Q=入场前权益/[entry*(1+fee)]；因此净单笔为 `[side*(exit/entry−1)−fee*(1+exit/entry)]/(1+fee)`。两边费用按实际名义金额收取，反手算两笔。权益每日按价格盯市，Sharpe用每日简单权益收益、252、rf=0。不要将负log价格变化当成真实短仓复利。

信号在t收盘后生成，在t+1真实开盘变化。时间戳为DataHub历史导出中的上海墙上时间（虽带Z），沿已接受源解释，不再加8小时。2020仅预热，不预持真实账户；每个评价年首开盘前账户空仓，可按此前已知目标在首开盘建仓，并在最后一个可观测开盘强制结束；最后一根新信号不交易。年末强平交易单列，所有候选/V1相同处理，跨年状态不伪称真实连续实盘。滤波/波动/目标状态从固定2020起点前缀连续，只有实际账户每年隔离。本设计避免用2024价格结束2023交易，也避免用跨年获利归属反向选参。五年度净值链为年度隔离账户顺次复投。选择门的累计MDD采用每日权益，全期展示另给逐分钟MDD，不混标。

## 参数审计与冻结家族

|类别|参数|本轮范围|预期影响与反例|
|---|---|---|---|
|保留用户核心|1m、T=120、order=1、h=1..5、多空对称、满单位|固定|改变频段/方向会改变研究对象；暂不扫描|
|可优化|entry_alpha|0.001 / 0.01 / 0.05|越小入场越严格，可能提高单笔，也可能只剩少数迟入场|
|可优化|exit_alpha|0.05 / 0.15 / 0.30|越大越容易反向退出，可能减少回吐也可能提前打断赢家|
|可优化|weight_power|0 / 1 / 2|偏重长窗口改变触发分布；不能假设减少抖动必增益|
|可优化|volatility_window|120 / 240 / 480|短窗更快适应风险，也可能随行情跳动；长窗较稳但响应慢|
|可优化的新机制|entry_confirm|1 / 3根|同方向并集连续成立才入场，不要求同一h持续；退出仍即时|
|可优化的新机制|cooldown|0 / 5根|退出当根记0，之后跳过5个闭合决策再准入；非零时禁止同棒反手，期间不积累确认|
|正确性锁定|σ严格滞后、raw开盘、零点初值、缺口校验、成本双边、期末处理|不优化|不能靠时间泄漏、漏收成本或删除亏损交易改善目标|
|数值保护|ddof=1、floor=1e−12、预热|继承V1|不以数值保护充当经济选参轴|

全家族3×3×3×3×2×2=324，包含V1配置与无确认/无冷却控制。完整参数身份去重，全部尝试保留，不追加网格。确认减少噪声但带来入场延迟；冷却减少重复试错但可能错过真反转，必须用完整账户衡量。结果后新增机制计为下一版，不能暗中加入本版。

## 时间、选择和证据

2020=warmup；2021—2023=consumed_development_material；2024、2025=本次冻结候选的后续重复历史检验（并非fresh OOS，原线程已看过历史）。2026=excluded，Parquet按年份有界读取，禁止一次把全部行情加载来设计。用户目标覆盖旧5m工作限制，此次继续1m。

逐年先运行此前冻结策略的blind命令，主控审阅、写理由，再运行family命令。每年仅允许一个结果前冻结的共同家族；前两年结果形成材料、同一固定家族整案重新选择。2023后锁定最终V2，2024/2025只跑V1与该V2，失败也不返工选择。前后回执摘要相连。

选择以2bp每边为主，完整交易数每年≥100（只是避免少样本优化的预注册下限，不证明独立）；累计净收益为正、日Sharpe≥V1、MDD≤V1+2百分点。可行集按**累计平均每笔净简单收益**降序、日Sharpe降序、交易数降序、稳定ID升序确定唯一点；平均单笔必须高于V1方可晋级。无可行点则报告无继任者并给最高单笔探索点，不伪称成功。每笔收益、年化和夏普都是重复历史统计，不外推。

参数主效应按其他五轴相同的配对差分及年度分布报告，不用全网格赢家位置代替因果解释。最终V2在2024/2025的共同净增量、每笔质量和夏普都原样报告；成本压力及多空拆分只诊断，不返选参数。
