# 首跳后状态风险诊断协议

日期：2026-09-07。结果前登记于本轮广义后续风险计算之前。

目的：同类严格30bp尾部事件复发过于稀少，因此改为检验**首跳已经发生以后，未来15分钟整体波动和路径不稳定性是否显著高于相同事前状态下的非事件时点**。这不是首跳预警，也不是Hawkes事件强度。

固定口径：

- 数据：2024—2025两指数已有分钟决定表；不读取2026；
- 锚点：既有分钟`first==1`首事件；
- 未来窗口：事件分钟之后`t+1..t+15`，不包含首跳分钟本身；不跨半日边界；
- 主连续指标：`future15_rms / sigma_pre_at_anchor`，其中future15_rms为未来15分钟收益RMS，sigma_pre为首事件发生前已知30分钟RMS；
- 辅助连续指标：未来15分钟绝对收益总和 / (`15 * sigma_pre`)；
- 辅助二元状态：future15_rms >= 1.5 * sigma_pre；1.5倍在看结果前固定，不搜索最优门槛；
- 对照：当前锚点分钟为已知非事件；同指数、同年、同上午/下午、同分钟位置；用锚点前两分钟的`logRV30`与`logRV480`匹配5个最近对照；匹配不使用未来结果；
- 统计单位：首事件；报告事件值与匹配对照均值之差，按指数和年份分别报告，再给总体；
- 推断：事件级随机符号翻转50,000次，仅作consumed-history探索；不称fresh OOS；
- 不改变原事件标签，不把本诊断结果反写为首跳预测成功。

若未来15分钟状态风险稳定升高，下一研究模块可命名为`post-shock state gate`；若没有稳定升高，则不继续复杂化首跳后门控。
