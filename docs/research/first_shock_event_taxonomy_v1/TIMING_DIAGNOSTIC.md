# quiet-first 时间定位诊断

日期：2026-09-07。使用V2修正后的事前状态匹配账本；只做描述性事件-对照比较，不重新训练V2模型。

目标：检查上一轮quiet-first事件中出现的“前1分钟最大绝对15秒收益较高”究竟是更早风险前兆，还是仅在冲击发生前最后一分钟才出现的启动信号。

## 方法

对62个`quiet_first`事件及其匹配对照，把事件分钟之前5分钟拆成五个互不重叠的一分钟窗口：`[-5,-4]`、`[-4,-3]`、`[-3,-2]`、`[-2,-1]`、`[-1,0]`分钟。每个窗口从已有3秒源观测按固定15秒as-of网格计算最大绝对15秒收益；不插值，不使用事件分钟本身。52个事件在全部所需特征上有至少一个可用匹配对照。

事件值减匹配对照均值：

| 距事件分钟开始 | 最大绝对15秒收益平均差 | 中位差 | 双侧符号翻转比例* |
|---|---:|---:|---:|
| 5—4分钟前 | +0.363bp | -0.441bp | 0.473 |
| 4—3分钟前 | +0.031bp | -0.405bp | 0.934 |
| 3—2分钟前 | -0.327bp | -0.464bp | 0.356 |
| 2—1分钟前 | -0.152bp | -0.518bp | 0.745 |
| **最后1分钟** | **+1.415bp** | **+0.970bp** | **0.0037** |

`*` 50,000次随机符号翻转，仅作为结果后探索诊断，不是fresh OOS确认性p值。

把最后一分钟的事件-对照差异，与此前四分钟差异的均值作事件内对比，平均额外抬升为 **+1.436bp**，中位数 **+1.283bp**，探索性符号翻转比例 **0.0031**。

15秒实现波动也呈同样的时间定位：前四个一分钟窗口没有稳定抬升，最后一分钟点估计增加，但探索性比例约0.056，弱于最大单次15秒动作。

分指数看，最后一分钟最大15秒动作的事件-对照平均差在科创50为约 **+1.95bp**（31个完整配对事件），中证1000约 **+0.62bp**（21个）；此前四分钟没有同方向的稳定抬升。

## 结论

当前证据更支持：**quiet-first事件在冲击分钟之前的最后一分钟开始出现短时动作增强，而不是在更早2—5分钟形成稳定的价格层跨尺度前兆。**

因此这个信号现阶段应称为“启动阶段快速检测候选”，不能称为更早的事前风险门控。它也解释了为什么B2新增命中主要出现在已经活跃的事件，而对真正quiet-first没有新增严格命中。

下一步不再扩大模型搜索，而是做一个严格的时距边界实验：固定同一最大15秒动作指标，分别要求至少提前1、2、3、5分钟，检查增量是否随提前量迅速消失。若只有最后一分钟有效，则价格历史对第一下完全突发风险的可预测部分应进一步下调，并把研究重点转向“快速检测＋首跳后的后续风险”，而不是继续称为首跳预警。

本轮不需要新增数据；所有输入来自已封存V2 Actions产物和修正账本。
