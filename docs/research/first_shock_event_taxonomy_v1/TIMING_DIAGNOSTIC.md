# quiet-first 时间定位诊断

日期：2026-09-07。使用V2修正后的事前状态匹配账本；只做描述性事件-对照比较，不重新训练V2模型。

目标：检查quiet-first事件中出现的“事件分钟之前最后一分钟最大绝对15秒收益较高”，究竟能否构成严格提前预警，还是只能在冲击起点附近成为检测信号。

## 方法

对62个`quiet_first`事件及其匹配对照，把事件分钟开始前5分钟拆成五个互不重叠的一分钟窗口：`[-5,-4]`、`[-4,-3]`、`[-3,-2]`、`[-2,-1]`、`[-1,0]`分钟。每个窗口从已有3秒源观测按固定15秒as-of网格计算最大绝对15秒收益；不插值，不使用事件分钟内部数据。52个事件在全部所需特征上有至少一个可用匹配对照。

事件值减匹配对照均值：

| 距事件分钟开始 | 最大绝对15秒收益平均差 | 中位差 | 双侧符号翻转比例* |
|---|---:|---:|---:|
| 5—4分钟前 | +0.363bp | -0.441bp | 0.473 |
| 4—3分钟前 | +0.031bp | -0.405bp | 0.934 |
| 3—2分钟前 | -0.327bp | -0.464bp | 0.356 |
| **2—1分钟前** | **-0.152bp** | **-0.518bp** | **0.745** |
| **最后1分钟 [-1,0]** | **+1.415bp** | **+0.970bp** | **0.0037** |

`*` 50,000次随机符号翻转，仅作为结果后探索诊断，不是fresh OOS确认性p值。

把最后一分钟的事件-对照差异，与此前四分钟差异的均值作事件内对比，平均额外抬升为 **+1.436bp**，中位数 **+1.283bp**，探索性符号翻转比例 **0.0031**。

15秒实现波动也呈同样的时间定位：前四个一分钟窗口没有稳定抬升，最后一分钟点估计增加，但探索性比例约0.056，弱于最大单次15秒动作。

分指数看，最后一分钟最大15秒动作的事件-对照平均差在科创50约 **+1.95bp**（31个完整配对事件），中证1000约 **+0.62bp**（21个）；此前四分钟没有同方向的稳定抬升。

## 严格提前量边界

V2对“至少提前1分钟”的定义，是告警必须在事件分钟最早可能开始之前至少60秒完成。

因此：

- `[-1,0]`这一窗口只有到事件分钟开始时刻`0`才完整可见，**不能作为至少提前1分钟的预警输入**；
- 真正满足至少提前1分钟要求的最新完整窗口是`[-2,-1]`；
- 而`[-2,-1]`及更早四个窗口均没有发现事件侧短时动作抬升。

所以当前最重要的结果不是“找到了最后一分钟前兆”，而是：**在严格可行动的1分钟提前量下，没有看到这个候选信号的增量；显著差异只出现在零提前量边界。**

## 结论

1. quiet-first事件在事件分钟开始前最后60秒确实更常出现较大的15秒动作；
2. 但这一60秒窗口只有在冲击分钟开始时才完全知道，因此现阶段最多属于**零提前量的启动检测信号**；
3. 真正可用于至少提前1分钟的`[-2,-1]`及更早窗口没有稳定差异；
4. 结合B0/B1/B2在25个科创50 quiet-first评价事件上均只命中3个，当前价格层证据**没有支持提前1分钟预测真正平静后的第一下冲击**。

下一步将研究目标分成两条，不再混称：

- `quiet-first pre-warning`：保持至少1分钟提前量；现有价格历史证据暂时偏弱；
- `onset / continuation detection`：允许零提前量或首跳发生后，研究能否快速识别已经启动的异常及后续风险。

现有数据足够继续，不需要新增数据或用户协助。下一轮优先研究首跳发生后的后续风险是否具有稳定的条件聚集性；若成立，它属于“首跳后的风险门控”，不是首跳预警。
