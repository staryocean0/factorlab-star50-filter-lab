## Working synthesis

The strongest surviving sources all contain an explicit **normal-state anchor + temporary displacement**:

- Overnight: market-closure/opening boundary supplies the anchor;
- R1: intact parent trend supplies the anchor;
- R2: intact parent range supplies the anchor.

By contrast, naked residual dislocation, naked overshoot, high activity around a displacement, and isolated shock magnitude did not produce robust standalone RMR evidence.

This is a working research hypothesis, not a theorem: **future broad discovery should search for distinct causal structural anchors before inventing new extreme scores.**

## Active discovery slot

**Intraday closure-boundary normalization (lunch break).**

Question: does the midday market closure create a repeatable displacement/normalization mechanism analogous to, but distinct from, Overnight? Specifically, after a measurable morning-close to afternoon-reopen displacement, does the early afternoon path systematically normalize relative to that lunch displacement?

If supported, it would broaden Overnight into a more general `market-closure boundary normalization` mechanism class. If unsupported, the Overnight effect remains specific rather than generic to market closure.
