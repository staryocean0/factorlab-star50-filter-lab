## 2. 结果一：把所有高频尺度先平均，可能抹掉真正的尺度变化

原型把Haar-2和Haar-4的滚动能量平均成一个高频量，再与工作尺度及过去波动作条件残差。第一轮合成正对照没有显示出期待的增量：在20%相同风险时点配额下，首事件召回均为60.87%，Clean桶内未来事件率由10.129%变为10.147%，差异区间包含0。

这不是风险假说被否定，而是必须先检查测量器有没有丢失信息。

一个确定性反例：令收益严格交替为`-a,+a,-a,+a,...`，方差尺度不变。对单位L2范数的单边Haar系数，有

- 长度2的系数能量为`2a²`；
- 长度4的系数能量为`0`；
- 两者平均仍为`a²`。

而方差为`a²`的独立白噪声，两个归一化尺度的期望能量都是`a²`，平均也是`a²`。**最短尺度明显变强，平均值却可能完全不变。** 这证明存在信息丢失，不声称这一反例已解释真实指数的所有异常。

因此保留原始V1结果，并另开“结果后诊断”：分别保留Haar-2和Haar-4的残差，不再先合并。各尺度能量是重叠Haar带代理，不是严格可加的傅里叶频带能量。

另一个解释边界：线性基线里加入线性残差，在不考虑正则化差异时，是加入原始高频能量的重新参数化；残差命名并不自动提供新的信息，也不证明结构因果效应。

## 4. 结果二：95%的“首事件召回”也可能来自随机告警

同一合成负对照中，在有效决定点随机选择约20%打告警：

- 138个已知首事件中，131个前面碰巧出现过告警，事件召回94.93%；
- 产生2300个告警段，一对一告警精确率只有5.70%；
- 全体决定点未来事件率13.35%，随机Clean桶内为13.08%，并未证明获得可靠的条件风险区分。

原因是匹配机会很多：若每分钟独立20%概率告警，一个事件前有14个可匹配时点，“至少一次告警”的概率为`1-0.8^14≈95.60%`。这是计数上的事实，不是预测能力。

所以**以后不能单凭事件召回晋级**。必须同时检查Clean桶内条件风险、漏入Clean的事件窗口份额、风险时点覆盖、告警段数量／精确率、幅度加权漏报和提前量。主评价继续保留真正未来窗口，不能因为唯一事件匹配好看就删除密集窗口的风险评价。完整的时钟／波动匹配、保留告警持续期的随机参照仍待市场阶段补齐；本随机反例不是那个完整参照体系。

## 5. 第一冲击的计时合同

一分钟收益在第`e`分钟收盘确认，变化最早可能从第`e-1`分钟收盘后开始。若要求至少提前一分钟，则告警时点必须满足`e-1-t >= 1`，即`t <= e-2`。

例如10:00—10:01这一分钟发生大变动：10:00的决定不能算作“提前一分钟预警”；09:59及更早的合格决定才算。本轮模型的未来15分钟目标包含紧邻下一分钟，但**严格事件召回另按最早可能起点计算**，不把窗口分类自动当成可行动提前预警。

“首事件”只指此前连续30个已知、无同类事件的分钟。缺口和未知不构成平静，簇首项也不等于已识别外生新闻。历史`available_at`仅是历史获取语义；序列防泄漏通过不等于已证明源数据的实时发布、接收延迟或生产可用性。

## 6. 冻结原型的精确定义与限度

原始市场候选协议在合成运行前登记于`docs/protocol.json`。其中数值为代码级固定常数的记录，不是可随意修改即可生效的调参配置。

尾部事件定义为绝对分钟log收益超过30bp且超过事件之前30分钟RMS的4倍；RMS下限1bp。30bp／4倍是依据已消费历史提案作的固定操作性选择，不是本轮发现的最优值，也不是计量意义的已确认jump。两指数使用同一绝对口径，同时保留各自标准化背景。

Haar窗口为2／4／8／16分钟，过去15分钟平滑；普通决定点为每半日第31—105分钟。最后15分钟不产生跨闭市预测。较早源缺口、过去480分钟有效度或事件静默期不满足时，决定点为Unknown。慢背景允许最多5%未知收益；短窗口必须完整。第一根缺前收的收益保持未知，不拼接午休或隔夜。

原型没有实现完整3秒／15秒主研究；只有已测试的秒级观测网格辅助函数，没有把它冒称新增DataHub OHLC产品。原型也没有完成集中位移／往返标签、订单簿机制、全部非重叠相位或个别源支持的敏感性。
