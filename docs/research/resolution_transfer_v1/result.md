# 科创50秒级分辨率与中证1000半日低通迁移：研究结果

两项计算均完成。秒级原始路径效率方差确实下降，但未找到可以宣布“最适合交易”的15s/30s最低点；低方差不能证明高频冲击消失。固定V2迁移中证1000的五年2bp/边指数模拟年化20.91%、Sharpe1.223、MDD16.93%。

## 1. 实际用了什么数据

秒级为588000和588080两只科创50ETF，2024/2025共483个已有源日、约475万条双标的原始记录。数据来自已独立验收的v1.1源3秒盘口，逐日读取前重新验证精确服务grant，每个文件SHA-256通过。2024-11-18/19源缺日保留，开盘初段及其他局部缺失不补价。价格主面为bid/ask中间价，latest trade price另作复核。

科创50指数3秒产品物理存在，但当前消费合同明确限制2020年之后读取；没有因本轮任务绕过契约。用户明确允许ETF替代，本轮据此使用已授权ETF。**这些秒级结果不能直接冒称科创50指数秒级结论。**

只在真实源观测上取3/15/30/60/300秒价格观察网格，不创建新的OHLC或交易K线产品。网格值只来自此前≤3秒且有效区间仍覆盖当前点的真实状态，缺失拒绝、不跨午休/隔夜补齐；无新报价但真实价格未变，会如实表现为重复价。数值公式是尾随的，完整覆盖判定是历史质量审计；本轮未建立实时路由供应链。

中证1000是DataHub已交付固定V3的原生1m指数OHLC，2020预热，2021—2025固定参数研究。与科创50V2使用同一个半日策略与账户算法；2026价格行未进入两项计算。

## 2. 15秒、30秒方差有没有下降？有

ER主回看固定30分钟，变化窗口固定60分钟，统一每5分钟观测。动态方差也严格取五分辨率共同有效窗口，而非各自挑选不同样本。

588000中间价的60分钟滚动ER方差中位数：

|观察粒度|2024|2025|
|---|---:|---:|
|5分钟|0.078133|0.070722|
|1分钟|0.017738|0.016020|
|30秒|0.011821|0.009598|
|15秒|0.008214|0.006330|
|3秒|0.005532|0.003314|

2025的30s/15s相对1m分别约降40%/60%，3s进一步下降。另一只ETF和15/60分钟路径窗口同向；最新成交价也同向。因此观察到的原始方差下降是真实测量事实，不是只挑一个好年份。

**但是它一路降到最细粒度，没有在15秒或30秒形成内点最低值。** 原始方差这个目标自身会偏向更细的采样，不能把最小值直接当交易最优。

## 3. 为什么不能据此说“高频已经很少、最适合交易”

第一，改变采样粒度会改变ER的分母。相同30分钟起终点，细网格观察到更多往返，绝对路程增大，ER往往下降。独立随机游走基准中，固定物理H、样本数n=H/Δ增加，ER均值近似随1/√n下降，方差可随1/n下降；这不代表原随机游走变平稳或更可预测。合成反例测试已通过。

2025年588000中间价：

|粒度|平均ER|原始ER方差|n×原始方差|价格不变比例|
|---|---:|---:|---:|---:|
|1m|0.2134|0.03406|1.0218|48.94%|
|30s|0.1711|0.02507|1.5042|61.39%|
|15s|0.1415|0.01949|2.3386|72.78%|
|3s|0.1083|0.01542|9.2500|90.84%|

归一化方差反而升高，相对方差CV²也从0.748升到1.314。n缩放只是在随机游走模型下的参照，不是适用于一切报价过程的“正确修正”，更不能反过来用它自动宣布5m最优。

第二，低方差可能代表“稳定在低ER”，或高比例重复价。588000最新成交价的2025年3s平均ER仅0.0200，1m为0.1485；更细的最新成交价也可能更多体现成交价往返和离散跳动。观察频率不等于新信息到达频率。

第三，即使观察间隔趋于零，也不能推出所有波动率相等。扩散增量方差会随Δ变小，但单位时间波动率仍可时变；跳跃也不会因切分而自动变成平滑走势。同一频率正弦的振幅增加，也会提高波动而不改变频率。因此波动率不是未解析高频成分的一一对应替代物。

微观结构文献也区分“忽略噪声而盲目加密”和“建模噪声后利用更多数据”；其结论针对方差估计，不等于任何秒级策略更盈利。[Aït-Sahalia、Mykland、Zhang，2005，作者机构页面](https://collaborate.princeton.edu/en/publications/how-often-to-sample-a-continuous-time-process-in-the-presence-of-/)。

## 4. 更细数据确实增加了哪些观察

同一30分钟窗口，588000中间价在粗网格观察到的总绝对路程，相对3s路径的中位比例为：

|粒度|2024|2025|
|---|---:|---:|
|1m|54.06%|44.87%|
|30s|67.99%|57.77%|
|15s|81.83%|72.22%|

这证明分钟端点会漏掉部分中间往返，15s/30s能提供额外路径细节。但“多观察到的路程”不是可兑现收益，更不是通道能捕获的收益。上述比例以3s为参考，不能说明3s以下不存在结构。

原型后验形态标签也未形成成熟的“能抓趋势/不可抓冲击”二分法：在588000中间价的1552/1591个非重叠30分钟有效窗中，ER≥0.6且单次位移占比<20%的严格定向标签仅2/3个；单次位移占比≥50%的窗为6/25个，净幅中位数仅约12.89/9.51bp；其余大量为mixed。这些严格阈值没有充分覆盖用户关心的大行情，不得把mixed解释成“没有趋势”，也不把高集中、低净幅窗称作巨幅高频冲击。

下一步要评价可捕获性，需要在实际可观察的触发时点之后，比较剩余方向位移、延续/折返与执行成本；完成整个窗口才知道的ER或最陡段持续时间只能作诊断。此轮没有发布新路由或择时频率。

## 6. 当前参数有没有数学上最佳的绝对波动率

没有这样的唯一数值。V2低通和斜率对log价格的振幅缩放是线性的，σ门槛也同比缩放。只将同一路径的log振幅乘0.25或4，信号逐点不变（在非退化数值范围内已通过测试）。也就是说，改变绝对波动幅度、保持路径时间形状不变，并不会自动切换V2。

真正改变结果的包括路径排列/时间尺度、当前与过去σ的变化、跳变/报价/执行时点，以及位移相对于固定费用的大小。最佳波动桶仍需要用“决策时已知状态→之后完整交易质量”的证据判断；它不会因15s原始ER方差变低就自动不再需要回答。

## 7. 验证与限制

135项测试通过。两年483日秒文件摘要与每次精确grant验证；两年各自输出及五年迁移工件摘要链通过。60分钟动态方差另限定共同有效支持，不能混用第一层summary里各自缺失后得到的动态中位数。最终图/报告使用 `final/resolution_summary.csv` 的严格共同时点口径。

两个真实ETF日、710个跨粒度案例用独立直接求和核对ER/路程/净位移，最大误差5.34e−14，截断未来观测值后价格网格不变。该检查不是全部秒级历史独立重放。五年V2迁移以独立现金/份额循环核对完整权益，最大误差2.66e−15；V1在每年全部输入前缀与原实现目标逐点一致。

原始输出、覆盖、年度回执、逐笔表见[工作流](workflow.md)。本轮所有结果均为重复历史研究，不是fresh OOS；没有新策略频率选择或生产权限。完成的是分辨率评估和固定参数迁移；因果路由与真实可捕获性仍待针对性研究。
