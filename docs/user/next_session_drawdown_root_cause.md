# 下一会话：持续回撤的K线根因与跨尺度关系

本任务来自用户2026-09-06的明确指令。它取代“继续通过降仓位改善MDD”及
“优先补盘中可得性/真实执行映射”的任务排序。上轮降仓结果是历史材料，
不是本轮研究成功的标准。本次仅更正语义和交接，不提前执行下一会话实验。

## 要回答的问题

在固定原策略、持仓规模和同一账户口径下，哪些价格路径属性及其跨尺度
关系，使策略出现连续净亏损、深回撤或长时间不能恢复？这些关系能否在
不同事件/年份重复出现，还是只是在有限样本里碰巧与亏损相遇？

允许使用后验分段、双向滤波、事后波形及未来完整区间作为解释性标签，
前提是清楚标注使用了未来，不能回填到当时的交易信号或伪装因果回测。
本轮先追求对历史机制的解释；能否实时识别另列结论，不作为发现机制的
先决条件。不要因不可因果获取而放弃可检验的后验研究。

## 先核对三个不同的“尺度”

| 维度 | 含义 | 研究要求 |
|---|---|---|
| K线采样周期 | 1m、已有5m偏移及15/30/60m、日视图 | 使用仓库既有数据；主工作图仍为5分钟，偏移不是独立市场 |
| 滤波频段 | 被保留/分析的物理频率区间 | 用交易分钟或交易日表达，明确滤波器响应、相位与过渡带 |
| 属性回看期 | 在多长历史区间内估计某个属性 | 与频段分开变化；窗口长度不是频率本身，重叠窗口不是独立样本 |

下一会话先做金融意图到数学量的预分析，再冻结有理由的有限尺度菜单及
比较预算。不要直接遍历所有周期、阈值后挑最能解释最坏回撤的一组。

## 属性研究方向（待预分析后冻结，不是预定答案）

- 单尺度属性：振幅/实现波动、路径效率与漂移、方向持续性、反转密度、
  波形完成度/周期稳定性、跳空及极端增量。每个量给出可证伪的金融解释，
  同一含义的重复代理应合并，避免堆砌指标。
- 跨频段关系：慢漂移相对工作振幅的大小、方向与相位关系、相邻频段的
  振幅比和调制、快波动是否不断抵消慢趋势收益、转折/尺度变化是否令
  固定低通与滞回发生持续错位。低频只是候选解释，不能预先认定主因。
- 跨回看期关系：短窗与长窗的效率/波动/漂移如何相互背离，属性是否在
  回撤前/回撤中发生转换，以及这种转换是否也常见于盈利区间。
- 机制必须回接原策略：K线属性→滤波/滞回信号行为→入场/反手/退出错误
  与真实记账损益。非正交滤波分量为负不是独立经济原因的充分证据；
  避免用策略同源的数学定义制造必然“解释”。

## 证据与巧合的检验

1. 固定原基线作为归因对象；重放同一持仓路径，不增设半仓/空仓/仓位
   择时来代替解释。区分已有不同执行口径，不能互换峰谷和收益。
2. 覆盖前十大回撤，也覆盖其余回撤、正常盈利区间和普通水下区间。
   分析峰→谷与谷→恢复，区分亏损强度、亏损聚集与回本缓慢。
3. 对联合条件使用互斥格或明确交互项；报告覆盖率、样本量、持续时间、
   条件收益分布、损失贡献、盈利反例。不能叠加重叠条件的边际贡献。
4. 比较跨事件、跨已消费年度和五分钟偏移的重复性；它们分别反映不同
   稳健性维度，不得把重叠窗口/偏移视为大量独立样本或新样本外验证。
5. “巧合”需要明确的原假设与数据对照。上轮日收益排列仅检验收益顺序，
   不足以检验“K线属性—策略亏损”关系。应预注册适合当前机制的匹配
   对照、保留时间依赖的分块/状态错位参照，必要时构造保留关键价格
   属性的替代序列并重跑固定策略；列明分别保留与破坏的关系。
6. 记录全部假说/属性/尺度尝试，控制多重比较与事后选择；报告效应量、
   不确定性及样本限制。没有显著证据不等于证明巧合，相关性也不自动
   等于根因。无法区分时明确“现有数据不足以判定”。

## 交付要求

- 根因候选对照表：金融解释、精确数学定义、采样/频段/回看期、是否用
  未来、预测的亏损形态、支持事件、反例和统计对照结果。
- 同时间轴图件：价格、关键频段、属性、原始信号/持仓、逐笔或逐段损益，
  至少让重大事件的解释可以直接核对，而不只有汇总回归或相关系数。
- 分别给出“有稳定关联/机制支持”“更符合机会性巧合”“证据不足”的
  判断；最后再列能否构造当时可得的因果代理。不得把可用代理误当原
  后验机制已经被证明。
- 文档、白皮书、代码、必要测试、可执行工作流及数据使用/尝试回执同步。
  不覆盖前三轮封存，不改变生产权限。
